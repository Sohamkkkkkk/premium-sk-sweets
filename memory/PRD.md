# SK Sweets Food Court — Website PRD

## Original problem statement
Build the official premium website for SK Sweets Food Court, a family-owned Indian sweet shop and food court in Dombivli East since 1999. Must feel like a luxury heritage brand — premium, elegant, traditional yet modern, warm and family-friendly. No prices anywhere — ordering through WhatsApp, Swiggy, phone. Real store photos should ONLY appear inside Gallery; every product surface must use premium, purpose-shot food photography.

## Architecture
- React SPA (react-router-dom v7) with Tailwind CSS + custom brand tokens
- Cormorant Garamond + Manrope typography via Google Fonts, lucide-react icons
- Frontend-only ordering via WhatsApp `wa.me` deep links, Swiggy URL, `tel:` links, Google Maps and Instagram external links
- Backend: unchanged FastAPI boilerplate (only /api/ hello + /api/status). No auth, no forms.
- Product photography: 32 original AI-generated images via Gemini 3.1 Flash Image (Nano Banana), saved to `/app/frontend/public/assets/products/*.png`. Generated by `/app/scripts/generate_product_images.py`. Uses EMERGENT_LLM_KEY.

## Personas
- Loyal customer WhatsApp-ordering a favourite (peda, samosa, khakhra)
- Celebration planner (birthday photo cake, wedding hamper, corporate gift)
- New visitor discovering via Google Maps / Instagram — needs to trust the brand fast
- Mobile-first shopper on smartphone

## What has been implemented (Feb 2026)

### Iteration 1 (baseline MVP)
- 9 pages: Home, About, Signature, Catalogue, Fast Food, Celebrations, Gallery, Reviews, Contact
- Home flow (13 sections in spec order), sticky nav (transparent→ivory-glass on scroll), premium mobile drawer
- Product catalogue with search, filter chips, deep-link `?category=`, NO PRICES, WhatsApp CTA per card
- Fast-food menu (6 groups), celebrations (3 occasions + 6 services), FAQ accordion, curated testimonials, floating WA + Call CTAs everywhere

### Iteration 2 (design refinement)
- **Image strategy overhauled**: real store photos moved into `STORE_PHOTOS` and used ONLY in Gallery + one hero background + gallery-preview teaser. Every other product surface now uses `PIMG` → local premium AI-generated food photos.
- **32 original premium product photos** generated via Gemini Nano Banana with editorial food-photography prompts (cream backgrounds, burgundy plates, gold accents, saffron/pistachio garnish). Stored in `/app/frontend/public/assets/products/`.
- **Gallery rebuilt**: CSS-column masonry, 6 category filter chips (all / interior / counters / sweets / products / store), fullscreen lightbox with prev/next buttons, keyboard ArrowLeft/ArrowRight, ESC to close, backdrop click closes, image counter.
- **Swiggy URL** updated to the real restaurant menu: `https://www.swiggy.com/menu/1269833?source=sharing`.
- Premium spacing (`py-28`/`py-40`), decorative gold hairlines, gold vertical flourish above hero headline, refined 92px hero type, italic gold-light accent word.
- Catalogue grew to **91 products** across 16 categories, each now mapped to its own visually distinct AI-photo (kaju katli diamonds, milk pedas with saffron, barfi with silver varq, anjeer barfi with visible figs, mysore pak on banana leaf, etc.)
- 100% pass on the testing agent for both iterations (98 + 91 assertions).
